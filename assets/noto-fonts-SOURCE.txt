Deadlane UI Regular / Bold (modified Noto Sans),
plus unmodified Noto Sans Symbols 2 and Noto Sans Math.
Original static TrueType font files from the official Noto repository:
https://github.com/notofonts/noto-fonts

Downloaded 2026-10-29 from main/hinted/ttf/:
NotoSans/NotoSans-Regular.ttf
NotoSans/NotoSans-Bold.ttf
NotoSansSymbols2/NotoSansSymbols2-Regular.ttf

The importer embeds font data, so WebGL needs no operating-system font.

DEADLANE modifications made 2026-10-29:
- Integrated U+2212 (minus) from Noto Sans Math and U+2605/U+2606
  (filled/outline stars) from Noto Sans Symbols 2 into BOTH main fonts.
- Copied decomposed TrueType outlines and horizontal metrics using fontTools
  TTFont, DecomposingRecordingPen, and TTGlyphPen. New outlines are unhinted;
  no source hint bytecode or cross-font function references were imported.
- Added the glyphs to the main Unicode cmap tables and glyph orders.
- Preserved original ascent 1069, descent -293, lineGap 0, and unitsPerEm 1000.
- Renamed the derivative family to Deadlane UI, full names to Deadlane UI
  Regular/Bold, and PostScript names to DeadlaneUI-Regular/DeadlaneUI-Bold.
  Updated derivative version/copyright/description and Unicode range metadata.
- Kept filenames and Unity GUIDs for existing Resources loading compatibility.
- Retained SIL OFL 1.1. Unmodified Math/Symbols2 remain as optional fallbacks,
  but all characters used by current runtime UI exist in each MAIN font cmap.

Tooling: system Python 3.9 with fontTools, inline Python processing (no C# change).
